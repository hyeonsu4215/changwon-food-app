# 출시 전 개선 계획

## 목표

창원대 학생이 조건을 복잡하게 설정하지 않아도 빠르게 메뉴를 추천받고, 추천 이유를 신뢰할 수 있는 모바일 PWA를 만든다.

## Phase 1: 추천 신뢰도와 날씨 설정

상태: IN PROGRESS

- 사용자가 켜고 끌 수 있는 "현재 날씨 참고" 설정을 추가한다.
- 설정은 `localStorage`에 저장한다.
- 날씨는 적합한 메뉴에만 작은 가산점을 주고, 다른 메뉴를 제외하거나 감점하지 않는다.
- 카테고리, 예산, 상황 등 사용자가 직접 선택한 조건을 날씨보다 우선한다.
- fresh 날씨일 때만 날씨 점수와 추천 이유를 적용한다.
- stale/unavailable 날씨는 추천에서 제외하고 간단한 안내만 표시한다.
- 실제 점수 계산에 반영된 조건만 추천 이유로 표시한다.
- 순두부찌개, 김치찌개, 육개장 등에 "시원한 메뉴"라는 잘못된 설명이 나오지 않게 한다.
- 추천 카드와 월드컵의 중복 태그를 제거한다.
- 기존 점수 1위는 유지하면서 같은 가게가 상위 결과를 과도하게 차지하지 않게 한다.
- 일반 사용자 화면에서 Supabase 연결 상태와 내장 데이터 fallback 같은 개발자 정보를 숨긴다.
- 위치 거부 시 창원대 정문 기준 거리 계산을 유지한다.

## Phase 1 완료 기준

- 더운 날 + 날씨 ON/OFF 시나리오를 검증한다.
- stale 날씨에서 점수와 이유가 적용되지 않는다.
- 날씨 OFF 설정이 새로고침 후에도 유지된다.
- 직접 선택한 찜/탕 등이 날씨 때문에 제외되지 않는다.
- 중복 태그가 없다.
- 같은 가게 반복이 완화된다.
- 기존 찜, 먹음, 후기, 검색, 월드컵, 룰렛, 지도 기능이 유지된다.
- 가능한 구문 검사와 테스트를 완료한다.
- Vercel Preview에서 모바일 화면을 확인한다.
