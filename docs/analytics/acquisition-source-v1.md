# Acquisition Source v1

Acquisition Source records only the allowlisted tag on the first `session_start` event of an Analytics session. It is separate from `source_context`, which describes where an event happened inside the app.

## Allowlist

- `direct`: no `src` query parameter
- `everytime`: Everytime distribution link
- `kakao`: Kakao distribution link
- `instagram`: Instagram distribution link
- `poster_qr`: offline poster QR
- `share`: a link generated by the app share UI
- `internal_test`: controlled production verification
- `other`: `src` exists but is empty or unknown

Raw query strings, raw source values, referrers, URLs, UTM values, and free text are never stored.
