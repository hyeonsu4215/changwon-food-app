묵찌 PICK! 개인정보 처리방침

시행일: 2026년 9월 1일

묵찌 PICK!은 이용자의 정보를 필요한 범위에서만 처리하고 안전하게 관리하기 위해 다음과 같이 개인정보 처리방침을 공개합니다.

1. 이용 방식

묵찌 PICK!은 별도 회원가입 없이 이용할 수 있습니다. 후기, 입맛 평가, 정보 제보처럼 서버 저장이 필요한 일부 기능에서는 해당 이용자의 데이터를 구분하기 위한 임의의 사용자 식별값을 사용합니다.

2. 처리하는 정보

사용 중인 기기에 저장되는 정보

  • 찜한 메뉴, 먹었어요 목록과 먹은 시각
  • 추천 조건, 입맛 설정, 날씨 참고 설정
  • 위치 사용 선택, 후기 닉네임과 작성한 후기 정보

먹었어요 목록 자체는 서버가 아니라 현재 사용 중인 기기에 저장됩니다.

선택 기능 사용 시 서버에 저장되는 정보

  • 임의의 사용자 식별값
  • 후기: 메뉴·가게, 닉네임, 별점, 위생·친절 평가, 후기 내용
  • 입맛 평가: 메뉴와 맵기·짠맛·단맛 평가
  • 정보 제보: 제보 유형, 대상, 제보 내용, 사용자가 직접 입력한 닉네임 또는 연락 메모, 처리 상태

서비스 이용 현황

서비스 개선을 위해 접속 시각과 임의의 세션 식별값, 추천 확인·재추천·메뉴 자세히 보기·지도 열기·공유·먹음 기록 추가 여부, 관련 메뉴와 가게, 추천 화면 종류, 유입 경로, 오류 여부를 기록할 수 있습니다.

이름, 학번, 전화번호, 이메일, 정확한 위치는 서비스 이용 현황에 저장하지 않습니다.

3. 이용 목적

  • 창원대 앞 메뉴 추천과 거리 표시
  • 후기, 입맛 평가, 정보 제보 기능 제공
  • 추천 품질과 서비스 안정성 개선
  • 오류 확인과 부정 이용 방지

4. 정확한 위치 이용

정확한 위치는 사용자가 허용한 경우 가까운 음식점까지의 거리 계산과 방문 후기 작성 가능 여부 확인 중에만 사용합니다.

정확한 위치는 서버에 전송하거나 저장하지 않습니다. 위치 사용을 허용하지 않아도 창원대 정문을 기준으로 추천과 주요 기능을 이용할 수 있습니다.

5. 보관 기간

  • 서비스 이용 현황: 기록된 날부터 2년
  • 정보 제보: 처리가 끝난 날부터 6개월
  • 후기·입맛 평가·임의 사용자 식별값: 이용 목적 달성, 삭제 요청 처리 또는 서비스 종료 시까지
  • 기기에 저장된 정보: 사용자가 앱에서 삭제하거나 브라우저·앱 데이터를 지울 때까지

처리 중인 제보는 처리가 끝날 때까지 보관한 뒤 위 기간을 적용합니다. 법령에 따라 더 보관해야 하는 경우에는 해당 기간 동안 보관할 수 있습니다.

웹사이트 제공과 파일 전송에는 Vercel을 이용합니다. Supabase는 해외 사업자가 제공하는 서비스입니다. 주요 서버 데이터는 대한민국 서울 지역에 저장되지만, 서비스 제공·보안·기술 지원 등을 위해 Supabase 또는 서비스를 지원하는 해외 협력 업체가 필요한 범위에서 정보를 처리할 수 있습니다. 이 과정에서 정보가 국외에서 일시적으로 처리될 수 있습니다.

서비스 제공에 필요한 경우 또는 법령에 근거가 있는 경우를 제외하고 이용자의 정보를 다른 곳에 판매하거나 임의로 제공하지 않습니다.
